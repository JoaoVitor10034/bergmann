# Clínica Bergmann - Landing Page

HTML, CSS e JavaScript puros, sem build.

## Visualizar
Abra a pasta no VS Code e rode `index.html` com a extensão Live Server (ou dê duplo clique no arquivo).

## Estrutura
- `index.html`: conteúdo e estrutura
- `css/style.css`: estilos, tokens de cor e responsividade
- `js/main.js`: WhatsApp, menu, abas, FAQ, mapa sob demanda e eventos (dataLayer)
- `assets/images/`: fotos (use WebP, com width/height e alt)

## Antes de publicar
1. Substituir os placeholders `[a confirmar]` (equipe, registros, tratamentos, convênios, avaliações).
2. Trocar os blocos de foto (`.ph` e `.arch`) por imagens reais e autorizadas.
3. Confirmar endereço, horários e número em `js/main.js` (`NUM`).
4. Incluir políticas de privacidade e cookies, redes oficiais, GA4/GTM, Open Graph e dados estruturados.
